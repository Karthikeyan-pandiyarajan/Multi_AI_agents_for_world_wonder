# World Wonders AI

An AI-powered travel planning system for exploring the world's wonders with specialized agents.

## Features

- **Wonder Scout** 🔍: Discovers and researches world wonders
- **Itinerary Architect** 📅: Plans optimized travel itineraries
- **Culture Chef** 🍽️: Recommends authentic local cuisine and dining experiences
- **Safety Guardian** ⚠️: Provides safety and health advisories
- **Master Concierge** ✨: Orchestrates all agents for seamless travel planning

## Setup

1. Clone this repository
2. Create a virtual environment: `python -m venv venv`
3. Activate the virtual environment: `venv\Scripts\activate` (Windows) or `source venv/bin/activate` (macOS/Linux)
4. Install dependencies: `pip install -r requirements.txt`
5. Add your Gemini API key to `.env` file
6. Run the application: `python main.py` or `streamlit run app.py`

## Usage

- Command line: `python main.py`
- Web UI: `streamlit run app.py`

## Requirements

- Python 3.8+
- Gemini API key
